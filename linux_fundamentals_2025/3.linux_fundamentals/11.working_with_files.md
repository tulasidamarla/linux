## Removing files
- `rm [file]` removes file
- `rm -r [dir]` removes the directory and its contents recursively
- `rm -f [file]` removes file forcibly and never prompts for confirmation

### Note: It's a good idea to double check what is going to be deleted with an ls command first.

## Copying files
- `cp [src_file] [dest_file]` to copy `src_file` to `dest_file`.
- `cp [src_file] [src_file_n ...] [dest_dir]` to copy all source files to `dest_dir`.
- `cp -i` to run copy in interactive mode.
  - If the destination file exists, `cp` will prompt before overwriting the file.
- `cp -r [src_dir] [dest_dir]` to recursively copy `src_dir` into `dest_dir`.
  - `Note:` If the destination directory doesn't exist, it will create the destination directory and copies the contents.
```
[root@symphony-dev-cluster1 test]# cp test.txt test2.txt
[root@symphony-dev-cluster1 test]# diff test.txt test2.txt
[root@symphony-dev-cluster1 test]# mkdir newdir
[root@symphony-dev-cluster1 test]# cp test.txt test2.txt newdir
[root@symphony-dev-cluster1 test]# ls newdir
test2.txt  test.txt
[root@symphony-dev-cluster1 test]# cp -i test.txt test2.txt
cp: overwrite 'test2.txt'? n

[root@symphony-dev-cluster1 test]# cp -r newdir newdir2
[root@symphony-dev-cluster1 test]# ls newdir2/
test2.txt  test.txt

[root@symphony-dev-cluster1 test]# cp newdir newdir3
cp: -r not specified; omitting directory 'newdir'

[root@symphony-dev-cluster1 test]# cp -r newdir newdir3
[root@symphony-dev-cluster1 test]# ls newdir3
test2.txt  test.txt
```

## Moving and Renaming files

- To rename a file/directory use `mv [src_file]/[src_dir] [src_file]/[dest_dir]`
```
## Renaming file
[root@symphony-dev-cluster1 test]# ls
firstdir  newdir2  newdir3  test2.txt  test.txt
[root@symphony-dev-cluster1 test]# mv test.txt test.renamed.txt
[root@symphony-dev-cluster1 test]# ls
firstdir  newdir2  newdir3  test2.txt  test.renamed.txt

## Renaming directory
[root@symphony-dev-cluster1 test]# mv newdir firstdir
[root@symphony-dev-cluster1 test]# ls
firstdir  newdir2  newdir3  test2.txt  test.txt
```
- To move a file/directory to a different location `mv` command can be used.
```
## To move a file to a different directory
[root@symphony-dev-cluster1 test]# ls
firstdir  newdir2  newdir3  test2.txt  test.renamed.txt
[root@symphony-dev-cluster1 test]# mv test.renamed.txt firstdir/
[root@symphony-dev-cluster1 test]# ls
firstdir  newdir2  newdir3  test2.txt
[root@symphony-dev-cluster1 test]# ls firstdir/
test2.txt  test.renamed.txt  test.txt
```
- Moving one file to another existing file, it will override the later.
```
[root@symphony-dev-cluster1 test]# cd firstdir
[root@symphony-dev-cluster1 firstdir]# ls
test2.txt  test.renamed.txt  test.txt

## The mv command runs in interactive mode. use -f for force override.
[root@symphony-dev-cluster1 firstdir]# mv test.renamed.txt test.txt
mv: overwrite 'test.txt'? yes
[root@symphony-dev-cluster1 firstdir]# ls
test2.txt  test.txt
```

## Sort based on file content
- Use `sort` command to sort content of a file.
  - `-r` for reverse sort order
  - `-u` for unique values
  - `-ru` for reverse and unique values
```
[root@symphony-dev-cluster1 firstdir]# cat names.txt
tulasi
tulasi
sayyad
sumanth
dipali
sindhu
manjula
prasad
[root@symphony-dev-cluster1 firstdir]# sort names.txt
dipali
manjula
prasad
sayyad
sindhu
sumanth
tulasi
tulasi
[root@symphony-dev-cluster1 firstdir]# sort -r names.txt
tulasi
tulasi
sumanth
sindhu
sayyad
prasad
manjula
dipali
[root@symphony-dev-cluster1 firstdir]# sort -u names.txt
dipali
manjula
prasad
sayyad
sindhu
sumanth
tulasi
```  
- Use `-k` followed by word number to sort based on nth word.
```
[root@symphony-dev-cluster1 firstdir]# cat experience.txt
tulasi: 18
sumanth: 10
manjula: 19
prasad: 10
dipali: 07

## Sorting based on first word
[root@symphony-dev-cluster1 firstdir]# sort experience.txt
dipali: 07
manjula: 19
prasad: 10
sumanth: 10
tulasi: 18

## Sorting based on second word
[root@symphony-dev-cluster1 firstdir]# sort -k2 experience.txt
dipali: 07
prasad: 10
sumanth: 10
tulasi: 18
manjula: 19
```

## Creating archives using tar
- `tar` command is used to create, extract or list contents of a tar using pattern, if supplied.
  - `tar - c|x|t f tarfile [pattern]`
- `Note:` tar command works without `-` also.
- `tar` options
  - `c` create a tar archive
  - `v` be verbose
  - `t` display the table of contents
  - `z` use compression
  - `f` use file
```
[root@symphony-dev-cluster1 test]# ls firstdir
experience.txt  names.txt  test2.txt  test.txt

## To create tar
[root@symphony-dev-cluster1 test]# tar cf test.tar firstdir/
[root@symphony-dev-cluster1 test]# ls
firstdir  newdir2  newdir3  test2.txt  test.tar

## To view the contents of a tar
[root@symphony-dev-cluster1 test]# tar tf test.tar
firstdir/
firstdir/test.txt
firstdir/test2.txt
firstdir/names.txt
firstdir/experience.txt


[root@symphony-dev-cluster1 test]# cd /tmp
## To extract tar contents 
[root@symphony-dev-cluster1 tmp]# tar -xvf /root/test/test.tar
firstdir/
firstdir/test.txt
firstdir/test2.txt
firstdir/names.txt
firstdir/experience.txt
```

## Compress/Uncompress files

- To compress files use `gzip` 
```
[root@symphony-dev-cluster1 firstdir]# ls
experience.txt  names.txt  test2.txt  test.txt
[root@symphony-dev-cluster1 firstdir]# gzip test.txt

## gzip command compresses the original file and appends gz extension
[root@symphony-dev-cluster1 firstdir]# ls
experience.txt  names.txt  test2.txt  test.txt.gz
```
- To uncompress files use `gunzip` or `gzip -d`.
```
## Using gunzip to uncompress
[root@symphony-dev-cluster1 firstdir]# gunzip test.txt.gz
[root@symphony-dev-cluster1 firstdir]# ls
experience.txt  names.txt  test2.txt  test.txt

[root@symphony-dev-cluster1 firstdir]# gzip test.txt
[root@symphony-dev-cluster1 firstdir]# ls
experience.txt  names.txt  test2.txt  test.txt.gz

## using gzip -d to uncompress
[root@symphony-dev-cluster1 firstdir]# gzip -d test.txt.gz
[root@symphony-dev-cluster1 firstdir]# ls
experience.txt  names.txt  test2.txt  test.txt
```
- To concatenate compressed files use `zcat`.
```
[root@symphony-dev-cluster1 firstdir]# ls
experience.txt  names.txt  test2.txt
[root@symphony-dev-cluster1 firstdir]# gzip names.txt
[root@symphony-dev-cluster1 firstdir]# ls
experience.txt  names.txt.gz  test2.txt
[root@symphony-dev-cluster1 firstdir]# zcat names.txt.gz
tulasi
tulasi
sayyad
sumanth
dipali
sindhu
manjula
prasad
```
## tar vs gzip

- gzip is a compressor
  - Compresses one file at a time
  - Cannot archive directories
  - Does not preserve directory structure
- tar is an archiver
  - Combines multiple files and directories into one archive
  - Does not compress by default
  - Preserves directory structure, permissions, ownership, timestamps

### Summary
- tar → packages files into one archive
- gzip → compresses the archive

- `Note:` typical usage of `tar` and `gzip` is to combine both packaging of files and compressing it.
 ```
 [root@symphony-dev-cluster1 test]# ls
firstdir  newdir2  newdir3  test2.txt
[root@symphony-dev-cluster1 test]# tar cvf test.tar firstdir/
firstdir/
firstdir/test2.txt
firstdir/names.txt
firstdir/experience.txt
[root@symphony-dev-cluster1 test]# gzip test.tar
[root@symphony-dev-cluster1 test]# ls
firstdir  newdir2  newdir3  test2.txt  test.tar.gz
 ```
## Disk usage

- The `du` command is used to findout howmuch disk space is used by a file
- The command `du -k` displays in kilobytes
- The command `du -h` displays in human readable format
```
[root@symphony-dev-cluster1 test]# ls
firstdir  newdir2  newdir3  test2.txt  test.txt
[root@symphony-dev-cluster1 test]# du test.txt
212	test.txt
[root@symphony-dev-cluster1 test]# tar cf test.tar test.txt

## Size of tar before compression
[root@symphony-dev-cluster1 test]# du test.tar
220	test.tar
[root@symphony-dev-cluster1 test]# gzip test.tar
[root@symphony-dev-cluster1 test]# ls
firstdir  newdir2  newdir3  test2.txt  test.tar.gz  test.txt

## Size of tar after compression
[root@symphony-dev-cluster1 test]# du test.tar.gz
4	test.tar.gz
```
