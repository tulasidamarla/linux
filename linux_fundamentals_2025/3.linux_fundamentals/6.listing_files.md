## Listing files
- `ls` command lists files.
- `ls -l` lists files in longer format. For ex,
  - `Permissions` like  `-rw-r--r--`
  - `Number of links` to the file or directory
  - `Owner Name` displays who the owner of the file/directory.
  - `Group Name` displays the group of file/directory that belongs to.
  - `Size` of the file/directory.
  - `Last modification time` of the file/directory.
  - `File name` of the file/directory.

```
[root@symphony-dev-cluster1 ~]# ls -l
total 2726300
-rw-------.  1 root root       1465 May 28  2024 anaconda-ks.cfg
-rw-r--r--   1 root root     179028 Aug  5 00:05 api.symphony-dev-cluster1.fyre.ibm.com.log
-rw-r--r--   1 root root       1390 May 16  2025 bash_profile
drwxr-xr-x   2 root root       4096 Jan 27  2025 cluster_setup
```
- `ls -l` list contents of directory, whereas `ls -ld` list the directory details.
```
[root@symphony-dev-cluster1 ~]# ls -l /etc/tmpfiles.d/
total 4
-rw-r--r-- 1 root root 117 Jun  2  2025 sos.conf
[root@symphony-dev-cluster1 ~]# ls -ld /etc/tmpfiles.d/
drwxr-xr-x. 2 root root 22 Jun 26  2025 /etc/tmpfiles.d/
```
- Hidden files begin with a period, sometimes called `dot files`.
- To show hidden files use option `-a` with ls as `ls -a`.
- Command and options can be combined. For ex, `ls -al`.
```
[root@symphony-dev-cluster1 rest]# ls
rest
[root@symphony-dev-cluster1 rest]# ls -a
.  ..  .classpath  .git  .gitattributes  .gitignore  .issues  .metadata  .project  rest  .secrets.baseline  .vscode  .whitesource
```

- `ls -t` list files by time.
- `ls -r` list files in reverse order.
- `ls -latr` long listing including all files in reverse order.

- `ls -F` displays file types.
  - `/` at the end represents directory
  - `@` at the end represents a link
  - `*` at the end represents an executable.
```
[root@symphony-dev-cluster1 rest]# ls -aF
./  ../  .classpath  .git/  .gitattributes  .gitignore  .issues/  .metadata  .project  rest/  .secrets.baseline  .vscode/  .whitesource

[root@symphony-dev-cluster1 rest]# ls -F /opt/ant/bin/
ant*  ant.bat  ant.cmd  antenv.cmd  antRun*  antRun.bat  antRun.pl*  complete-ant-cmd.pl*  envset.cmd  lcp.bat  runant.pl*  runant.py*  runrc.cmd
```

## Symbolic links

- A link points to the actual file or directory
- Use a link as if it were a file
- A link can be used to create a short cut
  - Use link for long file names or directory names
  - Use to indicate the current version of the software.

## The tree command
- `tree -d` displays all directories recursively in a tree format.
- `tree -c` displays all files and directories recursively with colorized output.

- `ls -R` also lists files and directories recursively
- `ls -d` displays only the directories inside.
- `ls --color` to colorize the output.
