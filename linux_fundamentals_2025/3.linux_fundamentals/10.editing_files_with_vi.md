## The VI editor
- To edit a file using `vi` the command is `vi [file]`.
- The `vim [file]` is improved version of vi with more features like syntax highlighting.
- The `view [file]` starts `vim` in read-only mode.

## The VI command mode and navigation
- The `vi` works in one of three modes `command mode`, `insert mode` or `line mode`.
- When `vi` starts it is in command mode.
- To go back to command mode from other modes press `esc` key.
- The command mode allows to navigate, perform search, copy/paste text and delete text.
- Here are some commonly used key bindings for navigation in command mode.
  - `k` up one line
  - `j` down one line
  - `h` left one character
  - `l` right one character
  - `w` right one word
  - `b` left one word
  - `^` goes to the beginning of the line
  - `$` goes to the end of the line.
- Here are some commonly used key bindings for delete operations.
  - `x` delete a character
  - `dw` delete a word
  - `dd` delete a line
  - `D` delete from the current position
- Here are some commands to change text
  - `r` replaces the current character
  - `cw` change the current word
  - `cc` change the current line
  - `c$` change the text from the current position
  - `C` same as `c$`
  - `~` reverses the case of the character
- Here are some commands for copy and paste.
  - `yy` yank(copy) the current line
  - `yw` yank the current word
    - `y3w` yank 3 words from the current position
  - `y<position>` yank the position
  - `p` paste the most recent deleted or yanked text
- For undo/redo
  - `u` for undo
  - ctrl + r` for redo
- For searching
  - `/<pattern>` to start a forward search
    - `n` for the next match
    - `N` for the previous match
  - `?<pattern>` to start a reverse search


 ## The VI insert mode
 - To insert text into a file enter insert mode.
 - To enter insert mode the following key bindings are used.
   - `i` insert at the cursor position
   - `I` insert at the beginning of the line
   - `a` append after the curser position
   - `A` append at the end of the line

## The VI line mode
- To use the line mode begin a key that starts with `:` and press enter.
  - `:w` writes(saves) the file
  - `:w!` forces the file to be saved
  - `:q` quit
  - `q!` quit without saving
  - `:wq!` write and quit
  - `:x` same as `:wq!`
### Navigation in line mode
- To use the line mode for navigation use the below commands and press enter.
  - `:n` positions the cursor at line number n, for ex `:15` takes to line number 15
  - `:$` positions the cursor at last line
  - `:set nu` turn on line numbering
  - `:set nonu` turn off line numbering
  - `:help [subcommand]` Get help
- summary of vi modes
```
Mode        Key
Command     Esc
Insert      i I a A
Line        :
```
