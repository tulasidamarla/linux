## The find command
- The command usage is `find [path] [expression]`
  - It recursively find files in path that matches the expression.
  - If no arguments provided it finds all files in the current directory.
```
[clusteradmin@symphony-dev-cluster1 ~]$ find
.
./.bash_logout
./.bash_profile
./.bashrc
./.zshrc
./.kshrc
./.bash_history
./.ssh
./.ssh/known_hosts
./.cache
./.cache/rhsm
./.cache/rhsm/rhsm.log
./sales.data
./.viminfo
./testumask
./a-dir
./a-file
```     
- The `find` command options are below.
- `-name` pattern find files and directories that match pattern.
- `-iname` pattern works like `-name` but ignores case.

```
[clusteradmin@symphony-dev-cluster1 ~]$ find /usr/sbin/ -name networkmanager
[clusteradmin@symphony-dev-cluster1 ~]$ find /usr/sbin/ -iname networkmanager
/usr/sbin/NetworkManager
```
- Use `*` for regular expressions.
```
## finding files that end with conv in /usr/sbin directory
[clusteradmin@symphony-dev-cluster1 ~]$ find /usr/sbin/ -name "*conv"
/usr/sbin/pwconv
/usr/sbin/pwunconv
/usr/sbin/grpconv
/usr/sbin/grpunconv
```
- `-ls` pattern performs and `ls` on each of the found items.

- `-mtime days` pattern find files that are days old.
```
## finding files that are morethan 10 days old and lessthan 40 days old in /usr/sbin directory
[clusteradmin@symphony-dev-cluster1 ~]$ find /usr/sbin -mtime +10 -mtime -40
/usr/sbin
/usr/sbin/sshd
/usr/sbin/criu
```
- `-size num` find files that are of size num.
```

```
- `newer file` pattern find files that are newer than the mentioned file.
```
## Find all files in /etc/ssh that are newer than /etc/passwd
[root@symphony-dev-cluster1 ~]# find /etc/ssh -type d -newer /etc/passwd
/etc/ssh
/etc/ssh/ssh_config.d
```
- `exec command {} \;` pattern runs command agains all the files that are found.
    - `\;` is to escape `;` in the command.

### Explanation of the above command
- `find` → searches for files and directories in the given path `/root/src/rest/rest/htdocs`
- `-exec` Tells `find` to execute a command on each found item.
- The `file` command examines a file’s contents and tells what kind of file it is.
```
file test.sh
# output: Bourne-Again shell script, ASCII text executable
```
- `{}`(placeholder) is replaced by the current file name that find has discovered one file at a time.
- `\;` marks the end of the -exec command.
  - The backslash `\` escapes the semicolon so the shell does not interpret it.
  - In the above example, ; needs to be escaped because they are executed as multiple commands seperated by ;

```
file /root/src/rest/rest/htdocs ; 
file /root/src/rest/rest/htdocs/MethodExampleResource1.png ;
file /root/src/rest/rest/htdocs/QueryMenuItem.html ;
...
...
```

## The locate command
- It is similar to `find` command which returns list of files that matches the given pattern.
- `locate` is fater than `find`.
   - The `find` command evaluates the given path and goes through each file and directory for the given search pattern.
   - The `locate` works on an index that typically rebuilds every day.
- The `locate` command results are not real time. So, when searching for files that are recently created chances are that the file may not be found.
- The `locate` command may not be installed on linux distributions.
