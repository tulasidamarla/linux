## Displaying the contents of Files
- The `cat` command displays contents of a file.
- It is used to display files that have static content.
```
[root@symphony-dev-cluster1 tmp]# echo "how are you" > temp1.txt
[root@symphony-dev-cluster1 tmp]# cat temp1.txt
how are you
```
- The `more` command allows to browse through a file page by page.
  - usage `more filename`.
- The `less` command is similar to `more` but it has more fetures.
- When using `more` or `less` commands use `space bar` to advance to the next page and use `return(or Enter key)` to advance to the next line and type `q` to quit the file.
- These commands are based on the VI editor.

### The head and tail commands
- By default the head and tail display 10 lines.
- `head` displays first 10 lines of a file.
- `tail` displays last 10 lines of a file.  
- To change the behavior use `-n` where n represents no of lines.
  - For ex `head -15 test.txt`
- Unlike `cat`, tail command displays data in real time, especially with log files. use `-f` option for following the file. For ex, `tail -f server.log`.


### The nano editor
- The `nano` editor is a simple editor and easy to learn.
- The `nano` editor is not as advanced as `vi` or `emacs`.
- If `nano` editor is not available try `pico`.
